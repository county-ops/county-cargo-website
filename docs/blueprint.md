# **App Name**: SwiftCargo

## Core Features:

- Hero Section: Display a clear and concise hero section with a strong value proposition.
- Features Section: Showcase unique features with relevant icons and descriptions.
- Vehicle Selection: Offer an interactive way for users to select the right vehicle for their needs.
- Call to Action: Conclude with a prominent call-to-action section to encourage user engagement.
- Cost Estimation: Estimate the shipping cost. The LLM acts as a tool, incorporating variables to determine the output, giving a general idea of what it may cost to ship an item.
- Testimonial section: Incorporate testimonials to showcase satisfied customers and build trust.

## Style Guidelines:

- Primary color: Trustworthy blue (#2563EB) for key accents and primary buttons, reflecting reliability and professionalism.
- Background color: Light gray (#F3F4F6), a desaturated tint of the primary color, provides a clean and modern backdrop, ensuring content clarity and readability.
- Accent color: Complementary orange (#16A34A) highlights secondary elements and CTAs, contrasting with the primary blue for enhanced visibility.
- Font Family: 'Inter', a grotesque-style sans-serif, will be used for both headlines and body text.
- Consistent spacing and a max-width container create a balanced and responsive design across all devices.
- Use icons to enhance visual appeal and provide quick understanding of key features and services.
- Subtle animations to enhance user experience during interactions, for example when tabs are selected in the Vehicle selection
