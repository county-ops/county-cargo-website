# **App Name**: Count Cargo App

## Core Features:

- Shipment Tracking: Allow users to track their shipments in real-time using tracking numbers.
- Rate Calculator: Provide a tool to calculate shipping rates based on destination, weight, and dimensions.
- Shipment Booking: Enable users to book shipments directly through the platform.
- Address Verification: Leverage a generative AI tool to verify shipping addresses, auto-completing where possible to avoid errors and reduce delivery failures. The LLM will use a tool to decide when and if to incorporate certain information in its output.
- Shipment History: Maintain a comprehensive history of all shipments made by the user.

## Style Guidelines:

- Primary color: Strong blue (#29ABE2) to evoke reliability and efficiency, aligning with the precision and security of logistics operations.
- Background color: Light blue (#E1F5FE), providing a calm, trustworthy and professional feel.
- Accent color: Complementary light green (#B7E1CD) for calls to action and successful states.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern and objective look. Use shade/cn ui library.
- Use clean, line-based icons to represent different shipping options, destinations, and statuses.
- Maintain a clean, well-organized layout that emphasizes usability.
- Incorporate subtle animations for loading states, successful form submissions, and shipment status updates.
