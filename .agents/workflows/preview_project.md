# Preview Project Workflow

This workflow details the commands required to start the local development server and preview the County Cargo (SwiftCargo) application.

## Step 1: Start the Development Server
Run the local dev server on port 9002:
```powershell
npm run dev -- -p 9002
```

## Step 2: Open Preview Link
Open your browser and navigate to:
[http://localhost:9002](http://localhost:9002)
